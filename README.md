# AudeoPlayer

本项目是基于 ***FFmpeg C api*** 的音视频播放器

项目依赖:
- FFmpeg
- SDL3

## 运行

```bash
./AudeoPlayer <file/directory> [<file/directory> ...]              # 单文件/目录或播放列表，循环播放
./AudeoPlayer <file/directory> [<file/directory> ...] --no-window  # 不创建窗口，只播放音频
```

播放列表循环播放，当前文件结束后自动切换到下一首；
单个文件打开失败时会打印`[ERROR]` 并跳到下一首，若一轮全部失败则退出。

### 控制

窗口模式：

| 按键 | 功能 |
| --- | --- |
| `Space` | 暂停 / 继续 |
| `N` / `P` | 下一首 / 上一首 |
| `↑` / `↓` 或 `+` / `-` | 音量 +5% / -5% |
| `→` / `←` | 快进 / 快退 5 秒 |
| `Q` / `Esc` | 退出 |

`--no-window` 模式（终端按键）：

| 按键 | 功能 |
| --- | --- |
| `Space` | 暂停 / 继续 |
| `N` / `P` | 下一首 / 上一首 |
| `+` / `-` | 音量 +5% / -5% |
| `.` / `,` | 快进 / 快退 5 秒 |
| `Q` | 退出 |

说明：

- `--no-window` 下不创建窗口、不初始化视频输出，视频数据会被丢弃；仅有视频流的
  文件会报错并跳过。
- 没有播放窗口时（`--no-window` 或纯音频文件）使用终端按键控制。
- 终端不是 TTY 时无法读取按键，但仍会按播放列表自动连播。
