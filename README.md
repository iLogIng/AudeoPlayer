# AudeoPlayer

本项目是基于 ***FFmpeg C api*** 的音视频播放器

项目依赖:
- FFmpeg
- SDL3
> 可能添加 spdlog 日志

## 模块分析

> 命名空间 avplayer

- 中间模块
    - 多线程
    - 流解析
        - 拆分为
            - 音频流
            - 视频流
    - 数据缓冲队列

- FFmpeg
    - 音视频处理
        - 解封装
        - 解码
        - 原始PCM
        - 编码
        - 封装

- SDL3
    - 创建窗口
    - 播放模块
        - Audio
        - Video
    - 音频输出
    - 视频渲染
    - 音频同步

### 模块划分

- 基础设施
    - 线程类型
    - 线程安全的阻塞队列
    - 线程安全的环形帧队列
    - 时钟
- 媒体层
    - 解封装
    - 音频解码
    - 视频解码
    - 重采样
- 输出层
    - 窗口
    - 音视频输出
- 固定5线程
    - 主线程
    - 解封装
    - 音频解码
    - 视频解码
- 同步层
    - 音视频同步时钟
